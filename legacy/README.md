# legacy / exploratory code

Early experiments kept for reference. **Not** part of the supported pipeline and not
imported by it.

- `CFG.py`, `CFG_new.py` — first attempts at CFG construction/visualization before
  `CFG_Extractor.py`. Superseded (hard-coded paths, single-graph, no int normalization).
- `Timeline_Parser.py`, `Timline_Parser.py`, `timeliner_attempt.py` — a side experiment on
  parsing execution timelines that did not make it into the final static-analysis approach.

These are frozen; do not build on them.
